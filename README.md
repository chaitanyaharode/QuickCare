# QuickCare – Online Doctor Appointment Website

QuickCare is a simple online doctor appointment website created as an internship project.

## About the Project

The main purpose of QuickCare is to make the doctor appointment process easier for patients. Instead of waiting for a physical appointment, patients can enter their details and select an available doctor and appointment time online.

## Features

- Simple and user-friendly design
- Patient appointment form
- Doctor selection
- Appointment date and time selection
- Patient details collection
- Responsive design for different screen sizes
- Appointment confirmation using JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Purpose

This project was created to demonstrate basic web development skills and to provide a simple solution for reducing the time required for physical doctor appointments.
